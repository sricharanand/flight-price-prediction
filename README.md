# flight-price-prediction
- An end-to-end regression pipeline to predict the price of flight itineraries. 
- Compares the performances of 7 models in scikit-learn, along with hyperparameter tuning for the 3 best-performing models, using the R^2 score.
- Language Used: Python
- Frameworks Used: Pandas, Scikit-Learn, Numpy, Matplotlib Pyplot, Seaborn
